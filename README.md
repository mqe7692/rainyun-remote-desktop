## 先确认你买的是不是 VPS 形态

雨云的游戏云（RGS）和普通云服务器（RCS）是两条独立产品线，游戏云内部又分两种形态，这决定了你能不能连远程桌面。

**VPS 游戏云**给你完整的系统权限，Windows 或 Linux 随你挑，SSH、RDP、VNC 都能用。带宽按所选配置走，IP 可选独立公网或 NAT 端口映射。配置从 2 核 4G 10M 起步，最高能到 8 核 32G 30M。

**面板游戏云**基于游戏面板，开服、传整合包、装插件全在网页上完成，带宽固定 50Mbps 上行，IP 是 NAT 映射、分配 10 个端口。它没有系统级登录权限，最低 1 核 2G 起步，主要卖给完全不想碰命令行的人。

要远程桌面，只能是 VPS 形态。买面板服之后再想连 RDP，只能退掉重买。

## 远程桌面连接：五步，两分钟

这段按实际操作顺序写，第一次连也不会卡住。

1. 在雨云控制台的服务器管理页找到连接信息，复制「远程连接地址」。
2. 在本地 Windows 搜索框输入 `rdp` 或「远程桌面」，打开「远程桌面连接」。
3. 把刚复制的地址粘进「计算机」栏。
4. 点左下角的「显示选项」，在「用户名」里填 `Administrator`。
5. 点连接，把控制台复制的远程密码填进弹窗，证书提示点「确定」，进入桌面。

用户名这一项要多说一句。`Administrator` 来自教程作者的经验表述（原话是「雨云 win 系统的用户名应该都是 Administrator」），不是官方文档的固定规定。你自己改过账户、或者用了自定义镜像，以控制台显示的为准。

还有一条容易被忽略的使用限制：有教程明确不建议在服务器上装浏览器上网，会占掉一部分内存。2 核 4G 的机器上，这条不是小题大做。

## NAT 还是独立 IP：远程桌面最容易踩的坑

NAT 机型便宜，代价是共享公网 IP，对外服务靠端口映射。开 Minecraft 服这种场景完全够用，但远程桌面默认走 3389 端口，这个端口在 NAT 环境下能不能映射、映射之后稳不稳，现有资料里没有明确说明。

下单前直接问客服端口映射规则，不要自己猜。这是本文唯一给不出确定答案的地方，但也是买错之后最麻烦的地方。

独立 IP 加价 150 元/月/个，不便宜。如果只是偶尔连上去改个配置、装个软件，NAT 省下来的钱够买好几个月机器；如果打算天天挂着远程桌面办公，独立 IP 更省心，至少不用担心端口映射变了连不上。

## 固定计费还是动态计费：挂机场景怎么算

雨云有两种计费方式，对远程桌面这种长期在线的用法影响很大。

**固定计费**月租写死，CPU 跑满还是空转都一个价，账目清楚。

**动态计费**基础租金很低，CPU 使用率超过 20% 的部分按「CPU 电量」日结额外收费，1 CPU 电量约等于 30% CPU 跑 1 分钟，单价 0.0005~0.001 元，系统每天还会赠送一定免费电量。

远程桌面是典型的持续运行场景。人不在电脑前，Windows 桌面、后台服务、系统更新照样在吃 CPU。有第三方测评提到，动态计费适合白天没人、晚上开几个小时的服，24 小时高负载反而更贵。把云服务器当办公桌面用，选固定计费更可控。

## 带宽和配置对远程桌面体验的影响

远程桌面对带宽的消耗取决于画面变化量。开终端、改配置文件、处理文档，10Mbps 上行绰绰有余；看视频、跑图形软件，画面一直在变，压力就上来了。雨云游戏云的上行带宽从 5Mbps 到 50Mbps 不等，VPS 常见档位是 10M 和 15M。
